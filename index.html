FinanceDesk

Your private company financials — stored securely in your own Google Sheet. No servers. No team access.

Setup guide — first time?
1

Create a Google Sheet

Go to sheets.google.com → New sheet. Copy the ID from the URL: docs.google.com/spreadsheets/d/THIS_PART/edit

2

Get OAuth Client ID

Go to console.cloud.google.com → APIs & Services → Credentials → Create OAuth 2.0 Client ID. Add file:// and your local URL as authorised origins.

3

Enable Sheets API

In Google Cloud Console → Enable APIs → Google Sheets API. Also enable Google Drive API.

4

Paste & Sign in

Paste your Sheet ID and Client ID above, then click Sign in. Sheets will be auto-created on first run.
